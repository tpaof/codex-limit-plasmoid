# Changelog

All notable changes to this project are documented here.

## 1.1.0 - 2026-09-02

- Added the optional `gpt-reserve Weekly limit` row.
- Positioned gpt-reserve after the standard weekly limit and on a separate
  tooltip line.
- Added multi-bucket rate-limit reads through the local Codex app-server.
- Kept local session-log parsing as a fallback for standard limits.
- Updated privacy, compatibility, and security documentation for the new data
  source.

## 1.0.0 - 2026-09-01

- First public-ready release.
- Added panel percentage and progress-bar display modes.
- Added configurable icon, icon size, label visibility, and refresh interval.
- Added remaining-limit progress bars to the popup.
- Added an original MIT-licensed project icon.
- Restricted helper output to an explicit rate-limit field allowlist.
- Added privacy, security, contribution, trademark, and release documentation.
