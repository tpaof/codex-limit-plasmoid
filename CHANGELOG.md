# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-09-01

- First public-ready release.
- Added panel percentage and progress-bar display modes.
- Added configurable icon, icon size, label visibility, and refresh interval.
- Added remaining-limit progress bars to the popup.
- Added an original MIT-licensed project icon.
- Restricted helper output to an explicit rate-limit field allowlist.
- Added privacy, security, contribution, trademark, and release documentation.
